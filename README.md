# 3D Room

Браузерный планировщик квартиры: от пустой схемы и размеров помещений до расстановки мебели и выбора отделки. Проект создаётся заново для репозитория [SHAN120186/3D_Room](https://github.com/SHAN120186/3D_Room) по предоставленным PRD, SPEC и чек-листу.

## Запуск

Нужны Node.js 24 и npm. В текущем окружении доступны Node.js 24.22.3 и npm 11.19.1.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite. Команды выполняются из корня репозитория, рядом с `package.json`. Для воспроизводимой установки по зафиксированному lock-файлу используйте `npm ci`.

```bash
npm run typecheck
npm test
npm run build
npm run preview
```

Сборка размещается в `dist/`. Приложению не нужны серверная база данных, API-ключи или платные 3D-сервисы. Состояние квартиры хранится в текущей вкладке; после перезагрузки страницы работа не восстанавливается.

## Сценарий

1. Выберите число жилых комнат и ориентировочную чистую площадь в м².
2. Выберите одну из трёх схем. Это приблизительная основа, её реальные размеры видны на плане.
3. Уточните стены, потолок, окна и двери. Линейные размеры вводятся в сантиметрах.
4. Перейдите к интерьеру: выберите комнату, добавьте мебель, назначьте отделку.
5. Осмотрите результат в 3D, измените освещение или перейдите в режим прогулки.

Стартовые схемы пустые. В обычном режиме 3D показывает выбранную комнату, а в прогулке — всю квартиру. При возвращении из интерьера к геометрии мебель и отделка сохраняются; конфликтующее изменение должно быть отклонено с объяснением.

## Управление

| Действие | Управление |
|---|---|
| Перенос предмета | Мышь; сетка 5 см, Alt отключает привязку |
| Поворот | R / Shift+R — по 15°; ручка поворота мышью |
| Точный сдвиг | Стрелки — 1 см, Shift + стрелки — 10 см |
| Удаление / отмена переноса | Delete / Esc |
| Отмена / повтор | Ctrl+Z / Ctrl+Y; поддерживается Ctrl+Shift+Z |
| Осмотр 3D | Вращение и приближение камерой |
| Прогулка | W A S D или стрелки, обзор мышью; высота глаз 160 см |

Горячие клавиши предметов не должны срабатывать во время ввода в поля. Положение за стеной или в пересечении подсвечивается и не сохраняется.

## Архитектура

| Часть | Назначение |
|---|---|
| React + TypeScript + Vite | Интерфейс и сборка |
| Three.js + React Three Fiber | Трёхмерная геометрия, материалы, камера |
| SVG | Размерный 2D-план и указатель |
| Общая модель квартиры | Стены, проёмы, комнаты, мебель и отделка в см |
| Геометрические функции | Проверки границ, пересечений и согласованности |
| Команды и история | Предпросмотр → проверка → атомарное применение |
| three-gpu-pathtracer | Браузерный режим качественного снимка |

Каталог содержит 35 оригинальных типовых изделий. Размеры и составные коллайдеры заданы в `src/domain/catalog.ts`, объёмная геометрия — в `src/components/FurnitureModel.tsx`. Источники текстур и условия использования перечислены в [ASSETS.md](ASSETS.md).
